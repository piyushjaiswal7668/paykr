# Security policy

Report vulnerabilities privately at:
https://github.com/piyushjaiswal7668/paykr/security/advisories/new

Include affected commit/version, reproducible steps using synthetic data, expected versus
actual behavior and impact. Never include live credentials, merchant SMS/email or payment data.
Do not test against someone else's deployment without their authorization.

Security fixes target the current `main` branch. There is no guaranteed response SLA or
maintained older release series yet. Coordinate disclosure with the maintainer before making
exploit details public. Ordinary non-sensitive bugs may use GitHub Issues.

Self-hosters must maintain dependencies, secure infrastructure, backups and device access.
See docs/SECURITY-REVIEW.md for existing review scope. Passing tests is not a security certification.
